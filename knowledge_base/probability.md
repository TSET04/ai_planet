# Probability – Core Concepts

## Basic Formula
P(E) = (Number of favorable outcomes) / (Total outcomes)

## Complement Rule
P(A') = 1 - P(A)

## Addition Rule
P(A ∪ B) = P(A) + P(B) - P(A ∩ B)

## Conditional Probability
P(A|B) = P(A ∩ B) / P(B)

## Bayes’ Theorem
P(A|B) = [P(B|A) P(A)] / P(B)

## Independent Events
If A and B independent:
P(A ∩ B) = P(A) P(B)

## Common Pitfalls
- Assuming independence without justification
- Forgetting to subtract intersection
- Wrong sample space definition

## Basic Probability
RULE:
- P(A) = favorable / total
COMPLEMENT:
- P(A) = 1 − P(not A)
USE:
- “At least one”, “at least two”, “not happening”

## Conditional Probability
FORMULA:
- P(A|B) = P(A∩B)/P(B)
STRATEGY:
- Convert verbal statements into set notation first

## Bayes’ Theorem
USE WHEN:
- Cause → effect problems
FORMULA:
- P(Aᵢ|B) = P(Aᵢ)P(B|Aᵢ) / Σ P(Aⱼ)P(B|Aⱼ)
COMMON TRAP:
- Forgetting denominator normalization

## Random Variables
EXPECTED VALUE:
- E(X) = Σ x·P(x)
SHORTCUT:
- E(aX + b) = aE(X) + b
VARIANCE:
- Var(X) = E(X²) − [E(X)]²

- "or" represents union
