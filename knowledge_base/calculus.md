# Calculus – Limits and Derivatives

## Standard Limits
lim x→0 (sin x)/x = 1  
lim x→0 (1 - cos x)/x² = 1/2  

## Derivative Definitions
f'(x) = lim h→0 [f(x+h) - f(x)] / h

## Common Derivatives
d/dx (xⁿ) = n xⁿ⁻¹  
d/dx (sin x) = cos x  
d/dx (cos x) = -sin x  
d/dx (e^x) = e^x  

## Product Rule
(uv)' = u'v + uv'

## Chain Rule
dy/dx = dy/du · du/dx

## Optimization Steps
1. Find f'(x)
2. Solve f'(x) = 0
3. Check maxima/minima
4. Verify domain

## Common Errors
- Forgetting chain rule
- Not checking endpoints
- Assuming stationary point is extremum

## Differentiation - Logarithmic Differentiation
USE WHEN:
- Products of powers
- Variable in base and exponent
- Complicated quotients
AVOID WHEN:
- Simple polynomial or exponential
TRIGGER:
- y = f(x)^a g(x)^b / h(x)^c → take ln both sides

## Maxima / Minima
STEPS:
1. f′(x) = 0
2. Use second derivative test OR sign change
SHORTCUT:
- For quadratic: a>0 → min, a<0 → max
- Vertex: x = −b/2a

## Integration - Substitution
USE WHEN:
- f′(x) exists inside integral
- Expression resembles derivative
CLASSIC FORMS:
- ∫ f′(x)/f(x) dx → ln|f(x)|
- ∫ x/(x² + a²) dx

## Definite Integrals - Symmetry Tricks
PROPERTIES:
- ∫₀ᵃ f(x) dx = ∫₀ᵃ f(a−x) dx
- f(x) odd → ∫₋a^a f(x) dx = 0
- f(x) even → ∫₋a^a f(x) dx = 2∫₀ᵃ f(x) dx
EXAM GOLD:
- Use symmetry before calculation
