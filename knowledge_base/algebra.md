# Algebra – Core Identities and Templates

## Linear Equations
We assume that the two sides of the equation are balanced.
We perform the same mathematical operations on both
sides of the equation, so that the balance is not disturbed.

For e.g. - 
3x + 4 = 13
Subtracting 4 from both sides
3x + 4 - 4 = 13 - 4
3x = 9
Dividing by 3 both sides
3x/3 = 9/3
x = 3

## Quadratic Formula
For ax² + bx + c = 0:
x = (-b ± √(b² - 4ac)) / (2a)

Discriminant D = b² - 4ac
- D > 0 → two real roots
- D = 0 → one repeated root
- D < 0 → no real roots

## Sum and Product of Roots
If roots are α, β of ax² + bx + c = 0:
α + β = -b/a
αβ = c/a

## Modulus Properties
|x| = a ⇒ x = ±a  
|x| < a ⇒ -a < x < a  
|x| > a ⇒ x > a or x < -a  

Always check domain before squaring.

## Logarithm Laws
log(ab) = log a + log b  
log(a/b) = log a - log b  
log(a^n) = n log a  

Domain: argument must be positive.

## Common Algebra Mistakes
- Squaring both sides without checking extraneous roots
- Ignoring domain of logs
- Cancelling terms across addition

## Quadratic Equations - Shortcuts
USE FORMULA WHEN:
- Direct roots needed
AVOID FORMULA WHEN:
- Only sum/product of roots is asked
SHORTCUTS:
- α + β = −b/a
- αβ = c/a
- α² + β² = (α+β)² − 2αβ
- 1/α + 1/β = (α+β)/αβ
OPTIMIZATION:
- For roots differing by k, use (α−β)²
- Factorization is faster if roots are integers

## Polynomials - Tricks
KEY STRATEGY:
- If f(a)=0, then (x−a) is a factor
- If f(a)=f(b), then (x−a)(x−b) divides f(x)−f(a)
SHORTCUTS:
- Remainder theorem beats long division
- Symmetric expressions → substitute x + 1/x = t
HIGH DEGREE:
- Rational root theorem first
- Sum of coefficients = 0 → x = 1 is a root

## Inequalities - Rules
IMPORTANT:
- Always check sign changes when multiplying/dividing
STRATEGY:
- Convert rational inequality into sign chart
- Critical points = zeros of numerator & denominator
QUADRATIC:
- Check roots + sign of leading coefficient

## Logarithms - Quick Rules
USE LOG PROPERTIES WHEN:
- Variable appears in exponent
- Products/quotients inside logs
IDENTITIES:
- log(aᵇ) = b log a
- log a + log b = log(ab)
- log a − log b = log(a/b)
COMMON TRAP:
- log(a + b) ≠ log a + log b
